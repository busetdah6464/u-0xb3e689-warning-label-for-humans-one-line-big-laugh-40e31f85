# Warning Label for Humans: One Line, Big Laugh

Entry for [Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) on make.fun.

One single-line safety warning label, at most 160 characters, that
should come printed on every human being: funny first, plausible
second. It reads like a real printed label, it is true about people
in general, and the laugh lands in the last few words.

`entry.py` is the readable source; `main.py` is the kit-packed entry
(`node <kit>/cli/makefun.mjs compress entry.py --out main.py`). Either
writes the line to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
